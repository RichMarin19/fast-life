feat: Add ObserverSuppressionActor to replace nonisolated(unsafe) flag

**WHAT:** Thread-safe actor for observer suppression flag

**Problem:**
`nonisolated(unsafe) var isSuppressingObserver` (WeightManager line 29):
- Bypasses ALL Swift concurrency safety checks
- Accessed from background thread (HealthKit observer callback line 569)
- Written from main thread (line 103, 108)
- NO synchronization between read/write → race condition

**Solution:**
ObserverSuppressionActor using Swift Actor pattern (~95 LOC):
- Actor provides automatic synchronization
- Only ONE task can access state at a time
- Swift runtime enforces thread safety
- Type-safe replacement for nonisolated(unsafe)

**Features:**
- isSuppressed() -> Bool: Check if observer should be suppressed
- suppress(): Enable observer suppression
- unsuppress(): Disable observer suppression
- suppressTemporarily(delay:): Auto-restore after delay

**Usage Example:**
```swift
let actor = ObserverSuppressionActor()

// In HealthKit observer callback (background thread)
Task {
    let suppressed = await actor.isSuppressed()
    guard !suppressed else { return }
    // Proceed with sync
}
```

**Why Actors Work:**
- Actor methods are async - automatically synchronized
- No manual locks needed
- Much safer than nonisolated(unsafe) data races
- Solves WeightManager's observer suppression race condition
