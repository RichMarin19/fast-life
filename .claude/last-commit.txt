Fix: Enhancement 8 - Drag-to-reorder data migration for Weight Tracker

WHAT:
Fixed drag-to-reorder failure for Weight Tracker cards caused by stale
enum preferences persisting in UserDefaults after Enhancement 7 removed
.milestone card type.

HOW (Root Cause):
Enhancement 7 removed .milestone from TrackerCardType enum but did NOT
clean up UserDefaults. CardManager loaded 4 preferences (including ghost
.milestone) but TrackerCardType.allCases returned only 3 cards, causing
index mismatches in drag-to-reorder operations.

THE FIX:
Added data migration filter in CardManager.loadCardPreferences() to
remove stale enum cases during load:

let validPreferences = decoded.filter { preference in
    CardType(rawValue: preference.id) != nil
}

RESULT:
- All 3 cards (Current Weight, Chart, Statistics) reorder consistently
- First launch after fix removes stale .milestone preference
- Debug logging tracks migration success
- Index calculations now align perfectly
