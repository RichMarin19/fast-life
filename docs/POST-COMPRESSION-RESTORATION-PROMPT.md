## 🎓 LESSONS LEARNED

### Why We Needed This

**Problem:** Across multiple sessions, we kept:
- Losing context about Weight Tracker priority
- Suggesting work on other trackers too soon
- Assuming phases were complete when they weren't
- Not asking user for status confirmation

**Root Cause:** Session compression removes conversational context but AI can't distinguish between:
- "Documentation says complete" (what's written)
- "User says perfect" (what's actually done)

**Solution:** Explicit restoration prompt that:
- States the priority clearly
- Requires status question FIRST
- Points to documentation to read
- Prevents assumptions

### Best Practices

1. **Always use this prompt** after compression
2. **Update prompt** when status changes
3. **Be explicit** about what's complete vs. what's documented
4. **Require confirmation** before proceeding
5. **Point to specific files** to read for current state
